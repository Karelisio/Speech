# Speech 1.0.3

Réglages par défaut fixés d'après le benchmark du Magic7 Pro, nettoyage IA plus rapide et plus sûr.

- **Nettoyage IA sur le GPU par défaut** : 1,4 s contre 2,3 s sur le CPU.
- **Décodage rapide** (Réglages → Nettoyage par IA) : le texte nettoyé recopie presque la dictée,
  le modèle valide donc plusieurs mots d'un coup au lieu d'un par un. Même texte, moins d'attente.
- **Garde-fou** : si l'IA remplace ou ajoute un mot (« Peux-tu » → « Peux-je ») ou retire une
  négation (« qu'ils ne soient »), le texte brut est gardé. Les hésitations, répétitions,
  auto-corrections, la ponctuation et l'orthographe restent corrigées.
- Prompt du nettoyage renforcé (pronoms, négations).
- Reconnaissance : 4 threads, CPU et « silences coupés » confirmés (NNAPI / XNNPACK sans gain).
