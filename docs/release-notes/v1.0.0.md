# Speech 1.0.0

Dictée vocale Android 100 % locale : rien ne quitte le téléphone (seul le téléchargement
initial des modèles utilise le réseau).

## Fonctions
- **Bulle de dictée** dans toutes les apps, au-dessus du clavier : toucher = démarrer / arrêter,
  appui long = maintenir pour parler, double tap = nettoyage IA on/off, glisser vers ✕ = masquer.
- **Insertion au curseur** par le canal du clavier (Android 13+), sans écraser le texte existant ;
  repli accessibilité puis presse-papiers.
- **Reconnaissance** : Parakeet TDT 0.6B v3 (défaut, ~0,7 s pour 10 s d'audio sur Magic7 Pro),
  Whisper large-v3-turbo et small en option.
- **Détection de la parole** (Silero VAD) : silences coupés, ou transcription en direct à chaque pause.
- **Nettoyage par IA** (Qwen 2.5 1.5B / 3B, llama.cpp) : hésitations, ponctuation, auto-corrections
  « non pardon… », sans rien ajouter ; prompt système gardé en cache.
- **Dictionnaire personnel**, **historique** des 50 dernières dictées, **benchmark** intégré
  (latence, RAM, taux d'erreur, endurance), **journal** exportable.
- **Mise à jour in-app**, assistant d'autorisations (dont guide MagicOS), thème Material You.

## Installation
1. Télécharger `speech-1.0.0.apk` ci-dessous et l'installer (autoriser l'installation depuis le navigateur).
2. Suivre l'assistant d'autorisations (micro, notifications, batterie, accessibilité).
3. Télécharger le modèle recommandé depuis l'accueil (670 Mo), puis Qwen 2.5 1.5B pour le nettoyage (1,07 Go).
