# Speech 1.0.6

Correctif : en 1.0.5, une dictée pouvait ne rien produire.

- Si le nettoyage IA échoue (modèle impossible à charger, mémoire GPU), le texte brut est inséré
  au lieu de rien.
- Contexte du nettoyage : repli automatique sur 2048 tokens si 4096 ne peut pas être alloué.
- Micro : une erreur de lecture passagère n'arrête plus l'enregistrement (arrêt seulement après ~1 s
  d'erreurs consécutives).
